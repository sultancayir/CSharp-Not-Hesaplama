# C# Console App | Sınav Notu Hesaplama

Bu proje, kullanıcıdan alınan sınav notlarına göre ortalama, harf notu ve geçme/kalma durumunu hesaplayan basit bir **C# Console Application** örneğidir.

---

## ⭐ Kullanılan Teknolojiler
- C#
- .NET Console Application
- Değişkenler
- Kullanıcıdan veri alma (`Console.ReadLine`)
- Koşullu ifadeler (`if - else`, ternary operator)
- Temel matematiksel işlemler

---

## ⭐ Uygulama Özellikleri
- Kullanıcı adı alma  
- 3 sınav notu alma  
- Ortalama hesaplama  
- Harf notu belirleme (AA – FF arası)  
- Geçti / Kaldı çıktısı verme  
- Program kapanmadan önce kullanıcıdan tuş bekleme  

---

## ⭐ Kod Dosyaları

- **Program.cs** → Uygulamanın tüm çalışma mantığı burada  
- **.csproj** → Proje ayarlarının bulunduğu dosya  

> `bin` ve `obj` klasörleri projeye dahil edilmemiştir çünkü derleme sırasında otomatik oluşturulan geçici dizinlerdir.

---

## ⭐ Çalıştırma

Terminalden:

```bash
dotnet run
```
